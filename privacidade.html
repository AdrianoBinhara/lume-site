O resumo

O Lume roda no seu Mac. Seus dados nunca passam por servidor nenhum do Lume: a memória fica no seu computador e não é vendida, alugada nem compartilhada com anunciantes. O único servidor do Lume é o de licença, descrito abaixo, e ele não vê sua memória.

O que o Lume acessa, e só com a sua permissão

  • Dados do seu Mac: conversas do iMessage e do WhatsApp Desktop, Notas e Contatos, lidos em modo somente leitura depois que você libera o acesso no macOS.
  • Pastas que você ligar: as pastas sincronizadas do OneDrive, Google Drive, Dropbox e iCloud Drive, ou uma pasta que você escolher. Nada é lido antes de você ligar, e arquivos que estão só na nuvem nunca são baixados.
  • Google: com o seu login, o Lume lê e busca e-mails do Gmail, cria rascunhos, envia e-mails que você aprovar, lê os eventos das suas agendas e cria eventos que você aprovar.
  • Outros serviços que você conectar: Granola, Linear, Otto, redes sociais e fontes de métricas, cada um pelo login, pela chave ou pelo arquivo de exportação que você fornecer.

Para onde os dados vão

  • Seu Mac: tokens de acesso ficam nas Chaves do macOS. A memória do Lume fica na pasta ~/Lume, no seu computador.
  • Seu Claude: quando você pede algo, o Lume usa o Claude Code instalado no seu Mac, com a sua conta da Anthropic, e envia a ela só o que for necessário pra responder ao seu pedido. O tratamento desses dados segue os termos e as configurações da sua conta Anthropic.
  • As IAs que você conectar em Agentes: Claude Code, Claude Desktop e Cursor consultam sua mente direto neste Mac. ChatGPT, Claude na web, Grok e os seus bots consultam por um endereço só seu, criado com o Tailscale, sem servidor do Lume no meio; você pode desligar esse acesso quando quiser. Cada IA vê só o que você liberar em Ajustar, em modo somente leitura. Senhas, códigos, cartões e documentos são ocultados antes de qualquer IA ler. O tratamento do que cada IA recebe segue os termos da sua conta nela.
  • Telegram, se você ligar: o Telegram é opcional. Se você criar o seu bot, as mensagens entre você e ele passam pelos servidores do Telegram.
  • Voz, se você ligar: áudios são transcritos e respostas faladas são geradas pela ElevenLabs, com a sua chave.

Dados do Google

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O Lume usa os dados do Google só pra executar o que você pede, não os usa pra publicidade, não permite que pessoas os leiam e não os usa pra treinar modelos de inteligência artificial.

Compra

O Lume é vendido pela Appsolutely LTDA. O pagamento é processado pelo Stripe, que recebe os dados do seu cartão ou Pix e o seu e-mail segundo a política de privacidade dele. O Lume não vê nem guarda dados de pagamento. O e-mail da compra é usado só pra entregar a chave, atender pedidos de reembolso e avisar sobre a sua licença.

Licença

O servidor de licença existe pra ativar o Lume num Mac, mover a licença de um Mac pro outro e reenviar a chave. Ele guarda exatamente isto:

  • o e-mail e o nome usados na compra;
  • o id da sessão de pagamento do Stripe;
  • um código anônimo do Mac ativo (um hash, que não identifica o computador fora do Lume) e o nome desse Mac, mostrado só quando você move a licença;
  • as datas da compra, da ativação e das trocas de Mac.

Nenhum dado da sua memória, das suas fontes ou das suas conversas passa por ele. Quem processa esses dados: Stripe (pagamento), MillionSend (envio do e-mail com a chave) e Cloudflare (onde o servidor de licença roda). Os dados ficam guardados enquanto a licença existir, pra que você consiga ativar, mover e reenviar a chave. Pra apagar tudo, inclusive a licença, escreva pra hi@appsolutelyltda.com.br.

O teste de 7 dias não pede conta nem e-mail: o servidor recebe só o código anônimo do Mac, pra contar os dias.

Como apagar tudo

  • Desconecte cada serviço em Fontes e em Agentes. Os tokens e os links de acesso são apagados do seu Mac.
  • Revogue o acesso do Google em myaccount.google.com/permissions.
  • Apague a pasta ~/Lume e o app.

English summary

Lume is a Mac app. User data never passes through any Lume server; the only Lume server is the license server, which stores the purchase e-mail and name, the Stripe session id, an anonymous hash of the active Mac and that Mac's name, for as long as the license exists (processors: Stripe, MillionSend, Cloudflare). Lume reads the user's local iMessage, WhatsApp Desktop, Notes and Contacts data in read-only mode, synced folders the user turns on, and Gmail and Google Calendar data through OAuth, only with the user's permission and only to fulfil the user's requests. Access tokens are stored in the macOS Keychain. Content needed to answer a request is sent to the AI provider the user already uses through their own Claude Code account. AI apps the user connects (Claude, ChatGPT, Cursor, Grok, the user's own bots) query the user's memory in read-only mode, locally or through a private address the user controls; passwords, codes, cards and documents are redacted first. Lume's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not used for advertising, is not read by humans, is not sold and is not used to train AI models. Users can revoke access at any time at myaccount.google.com/permissions and by disconnecting inside Lume. Payments are processed by Stripe. Contact: hi@appsolutelyltda.com.br.

Google user data

With the user's permission, through Google sign-in, Lume accesses:

  • Gmail (gmail.readonly, gmail.compose): reads and searches the user's emails to answer the user's requests, creates drafts, and sends an email only after the user approves it.
  • Google Calendar (calendar.calendarlist.readonly, calendar.events): reads the user's calendars and events, and creates an event only after the user approves it.
  • YouTube (youtube.readonly): reads the user's channel information and statistics.

How it is used. Only to provide the features the user asks for inside Lume: searching and summarizing emails and events, answering the user's questions about them, and drafting replies or events the user approves.

Where it is stored. Only on the user's Mac: access tokens in the macOS Keychain, and email and calendar content in an encrypted local index. Lume has no server that receives Google user data.

Sharing. Google user data is not sold, not used for advertising and not shared with third parties. When the user asks Lume something, only the excerpts needed for the answer are sent to the AI provider the user already uses with their own account (Anthropic's Claude), to produce that answer. If the user connects another AI app to Lume, email content is available to it only after the user turns it on for that app.

No AI training, no human access. Google user data is not used to develop, improve or train generalized AI or machine learning models, and is not read by humans, except with the user's explicit consent, for security purposes or to comply with the law.

Retention and deletion. The data stays on the user's Mac until the user deletes it. "Apagar tudo" (delete everything) in Lume's settings removes the index and the tokens, disconnecting Google inside Lume stops all access, and access can be revoked at any time at myaccount.google.com/permissions.

Limited Use. Lume's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
